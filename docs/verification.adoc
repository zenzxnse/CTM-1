= Verification record

Date:: 2026-09-11
Status:: Pending final source-tree verification

This record is intentionally a procedure until the final shared-tree build and
tests are run. It distinguishes specified build profiles from observed behavior.

== Required checks

[cols="2,3",options="header"]
|===
|Check |Evidence to record
|Native Linux Debug and Release |CMake configure output, build output, test case count and API run
|Sanitizer profile |Address and undefined behavior results, including environment limitations
|Workbench |Dependency lock check, type check, format check and static build output
|Telemetry workflow |Accepted and rejected ingestion, freshness, unknown values and event stream
|Interpretation efficiency |Cold and warm cache metadata, context size, provider usage and timing
|Reconciliation |Model revision, changed binding, explicit issue and current generation
|Operational journal |Replay, checksum and torn-tail behavior with required records preserved
|Package smoke |Installed executable, resources, read-only runtime and health endpoint
|Windows x64 |Native MSVC Debug/Release execution and API checks
|Windows Server |Native service, restart, firewall and API checks on a named release
|Docker Linux |Container health, non-root identity, readiness and runtime write behavior
|Docker Desktop Windows |Same container checks performed through Docker Desktop
|Linux Mint and TCL Linux |Named release, ABI, CPU and package execution
|Vendor compatibility |Exact product/version, reviewed artifact and runtime evidence
|===

== Reproduction commands

[source,shell]
----
npm --prefix workbench ci
npm --prefix workbench run check
npm --prefix workbench run format:check
npm --prefix workbench run build
cmake --preset debug
cmake --build --preset debug --parallel 2
ctest --preset debug
cmake --preset release
cmake --build --preset release --parallel 2
ctest --preset release
python3 benchmarks/live.py --build-dir build/linux-release \
  --save build/benchmarks/live.json
----

Only the release owner runs these commands. A compile is not a test, a container
health check is not native Windows evidence, and a mock provider is not a live
llama.cpp interoperability result.

== Current limitations

No live machine, controller, EcoStruxure runtime, AVEVA runtime, Ignition gateway,
native Windows host or TCL device is available in this record. No claim is made for
industrial certification, process safety, dimensional unit conversion, historian
retention or provider interpretation quality on held-out requests. A live provider
run must record model weights, chat template, provider version, privacy approval and
raw usage metadata.
