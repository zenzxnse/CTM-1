= Correctness review notes

Review date:: 2026-09-11
Status:: Integration review pending final execution

The active review follows the boundaries in ADR 0017. The native service must
validate the machine model and every telemetry batch before state replacement,
retrieve a bounded relevant subgraph, reject provider selections outside that
subgraph, and resolve only declared bindings. A same-ID semantic change is a
reconciliation conflict. Missing and stale values remain explicit.

The provider boundary must preserve failure isolation. A provider timeout, malformed
JSON or schema violation returns an understandable error and does not stop telemetry
or invalidate an existing view. Static prompt content precedes variable context and
operator text. Cache hits never bypass current native validation.

The HTTP boundary must retain `/api/v1` envelopes, body limits, origin policy,
bounded streams and server-authoritative view identity. Diagnostic logs may lose
low-severity entries only with a visible counter. Required operational records use
the framed journal and cannot be silently dropped.

The remaining review gates are native build and test execution, mutation checks,
workbench checks, package smoke, Docker profiles, Windows execution and benchmark
measurement. Current files and executed output, not handoff claims, determine each
evidence label.
